# 声づくり（Google AI Studio の Generate speech で作る場合）

API キーを使わずに、AI Studio の画面で声を作る手順です。
API キーがある場合は `tools/tts_gemini.py` で同じ内容を1コマンドで作れます。

## 設定

| 項目 | 値 |
|---|---|
| モデル | Gemini 3.8 Flash TTS |
| 声（Voice） | **Algenib**（説明は Gravelly＝少しかすれた低い声）。別案: Charon / Orus / Alnilam |
| Temperature | 1（下げると壊れやすい、という過去の記録に合わせる） |
| 話し手 | 1人（Single speaker） |

渋さが足りないときは、3.8 の **Voice design（声を文章で作る機能）** で
「50代の男性。低く、少しかすれた声。ドキュメンタリー番組のナレーター。」と作って試してください。

## Style（口調）欄に貼る文

```
低く、落ち着いた、渋い中年の男性ナレーター。ドキュメンタリー番組の語り。声を張らず、一語ずつ確かめるように、ゆっくり。文の終わりは静かに落とす。句点のあとは一拍おく。空行のところ（場面の変わり目）は、ふつうの句点より長めに間をとる。
```

## 本文欄に貼る文（1回で全文を読ませる）

```
この秋、日本では、情報漏洩の公表が相次ぎました。

ニュースでは「AIを使った新しい攻撃だ」とも言われています。

でも、一次情報を読むと、見え方が少し変わります。

警察庁によると、今年の上半期、ランサムウェアの侵入経路が分かった、さんじゅうろっけんのうち、半分の、じゅうはっけんは、ブイピーエヌ機器からでした。

アメリカのベライゾンの調査でも、侵入の入口のトップは、初めて「ソフトの穴を突く手口」になりました。

新しいのは、手口ではなく、速さ。
AIが、古い穴を突くスピードを上げている。いまのところ、それが有力な見方です。

そして、もう一つ。持っていないデータは、漏れません。

あなたが使っていないサービス、いくつ残っていますか。

ウラトリ。テクノロジーのニュースを、一次情報で深掘りします。
```

数字は読み間違いを防ぐため、ひらがなで書いてあります（画面と字幕は `script.json` の `text` の表記のまま）。

## できた WAV の置き場所

`episodes/uratori-01-1min/audio/narration.wav` に置き換えて、リポジトリの一番上で次を実行します。

```bash
./make_video.sh uratori-01-1min
```

文の切れ目は無音から自動で見つけます（`tools/build_timeline.py`）。
「文の切れ目の候補が足りません」と出たら、`--thresh -34` のように少し上げてください。

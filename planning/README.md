# 企画（ネタ集め → 台本）の置き場

企画の正本は Notion にある（ページ「Youtube」→ `00_方針と収益化ファクター` / `01_リサーチ→台本の流れ（SOP）` / `ネタ帳（トピック候補）` / `02_台本案` / `03_参考チャンネル分析` / `04_台本テンプレート`）。
このフォルダには、制作パイプライン（`episodes/<回>/script.json`）と企画をつなぐための、変わりにくいものだけを置く。

- `factors.md` … ネタを採点する8つのファクターと重み（Notion のネタ帳の列と同じ）
- `script_template.md` … 台本の骨組み（PROLOGUE → CTA → 第1〜4章 → 結び）と、script.json への落とし込み方

## 流れ（要約）

1. 週1回、ネタ帳に候補を5〜10件入れる（投票ランキング・Reddit・海外チャンネルの人気順・コメント欄・公的統計）。
2. 8ファクターで採点し、合計35点以上（満点52.5）をリサーチへ。
3. 一次情報（論文・公式統計・本人発言）を3つ以上当て、出典台帳に札（公式発表／調査報告／本人の発言／報道）と確認の状態を書く。
4. テンプレートの骨組みで台本を書く。CTAはPROLOGUE直後に1回・20秒以内。反転ポイントは第2章の頭（ミッドロール直後）。
5. 広告適性チェック（自殺・自傷・性的・暴力・摂食障害・児童の描写なし。健康・お金は研究者名を出し、断定しない）。
6. `episodes/<回>/script.json` に sentences / scenes / sources を転記して制作へ。
7. 公開7日後に CTR・平均視聴時間・離脱点をネタ帳のメモに戻し、採点の重みを見直す。

# ネタの採点ファクター（各1〜5点）

収益 = 再生数 × RPM。再生数は「クリックされる（好奇心）× 見続けられる（意外性）」、RPMは「視聴者層 × 広告枠数（8分以上でミッドロール）× 広告適性」で決まる。

| ファクター | 重み | 何を見るか |
|---|---|---|
| 好奇心 | ×1.5 | 実際に人が聞いている問いか（投票ランキング・検索・Reddit の票数・コメント欄） |
| 意外性（へえ度） | ×2 | 通説と一次情報のズレ＋見終わった後に世界の見え方が変わる学びの深さ |
| 広告適性 | ×1.5 | 自殺・自傷・性的・暴力・摂食障害・児童に触れないか |
| 単価期待 | ×1 | 視聴者が社会人・購買力あり・ビジネス寄りか |
| 長尺耐性 | ×1 | 10〜15分、章立て4つ分の奥行きがあるか |
| 一次情報 | ×1 | 論文・公式統計・本人発言が取れるか |
| 普遍性 | ×1 | 1年後も再生されるか |
| 競合の空き（ありそうでなかった度） | ×2 | YouTube検索を視聴回数順にして上位10件に同テーマ10万回超が無いか |

合計 = 好奇心×1.5 + 意外性×2 + 広告適性×1.5 + 単価期待 + 長尺耐性 + 一次情報 + 普遍性 + 競合の空き×2（満点55）。38点以上を優先。

## 「ありそうでなかった」の判定（先にやる）

次の3型のどれかに当てはまるものだけを候補にする。

1. 海外既出・日本語未開拓：英語圏の論文・報道では有名だが日本語YouTubeに無い。
2. 有名な話の「その後」：広く信じられた研究が再現失敗・反論・訂正を受けている。
3. 二つの領域の接続：別々に知られた2つの事実を一次情報でつなぐと新しい問いになる。

既出判定はYouTube検索を視聴回数順にして上位10件を見る。10万回超の同テーマがあれば競合の空きは2以下。広告適性が2以下のものは、点数に関係なく扱い方（非グラフィック・教育的）を決めてから。

## 押さえておくルール（2026年10月時点、一次資料は YouTube ヘルプで再確認すること）

- 収益化の参加条件: 登録者1,000人 + 直近12か月の総再生4,000時間 または 直近90日のショート1,000万回。2027年2月1日から新規は 8,000時間 / 2,000万回に倍増と報道。
- 「一般的、または繰り返しの多いコンテンツ」（2025年7月改定）: テンプレ台本＋AI音声＋フリー素材の量産は収益化不可。固有の人物・場面・一次情報・制作者の視点があれば AI 利用でも可。
- 2026年7月の明確化: 反復・テンプレ型 / 不快・苦痛を与える目的 / AIペルソナが健康・金融を語る、の3類型は収益化不可。
- 2026年1月の緩和: 自殺・自傷などに触れても、非グラフィック・教育的なら全額収益化可。児童虐待・摂食障害は引き続き制限。
- ミッドロール広告は8分以上。場面転換に自動配置される。

## 公開後に見る指標（目安。自チャンネルの実測で上書きする）

- CTR 5%以上（8%超で良好）
- 平均視聴時間: 10分動画で4分以上
- 最初の30秒の維持率 70%以上
- 視聴者層: 25〜54歳が過半

# 台本テンプレート（考える夜／ウラトリ共通）

所要10〜15分、3,000〜5,000字。1分 ≒ 300〜350字。

| 区間 | 目安 | 役割 | ルール |
|---|---|---|---|
| PROLOGUE | 60〜120秒 | つかみ。具体的な人物か場面から入る | 時間と場所を最初の一文に。最後にタイトルの問いを一字一句そのまま言う |
| CTA | 15〜20秒 | チャンネルの約束 | 登録の呼びかけは1回 |
| 第1章 | 2〜3分 | 仕組み | 有名な実験か理論を1つ。専門用語はその場で一行解説 |
| 第2章 | 2〜3分 | 反転 | ミッドロール直後に置く。一次情報の札を出す |
| 第3章 | 2〜3分 | 日本・日常への接続 | 公的統計か日本の事例を1つ。視聴者を主語に |
| 第4章 | 2〜3分 | 反論・限界・応用 | 再現失敗や反対の研究を正直に。処方箋は1つ |
| 結び | 60秒 | 問いを視聴者に返す | 答えを言い切らない |
| 次回 | 15秒 | 回遊 | 関連動画を1本だけ |

## 文体

- 一文は短く。「。」で一拍。体言止めは3回に1回まで。
- 数字は1場面に2つまで。出すときは札の種類（公式発表／調査報告／本人の発言／報道）を画面に出す。
- 「〜である」調（考える夜）、「〜です・ます」調（ウラトリ）。混ぜない。
- 研究が1本しかないことは「〜という研究がある」。複数が一致するときだけ「〜と分かっている」。
- 固有名詞は初出でフルネーム＋肩書き＋年。

## script.json への落とし込み

- `sentences`: 一文ずつ。数字を含む文は `read`（読み方）を別に書く。
- `scenes`: 場面の型（`blender` / `news` / `dots` / `bars` / `keymsg` / `question` / `endcard`）と画面に出す文字。
- `sources`: 出典台帳。`kind` は4種の札、`status` に確認の状態（一次で確認／二次のみ）。

【キーワード3つ】

PROLOGUE

CTA

（登録の呼びかけ、1回）
